# Building Materials

## Material Sources
| Material | Harvested From |
|----------|----------------|
| Moloz (Debris) | Wrecked vehicles, dumpsters, market stalls |
| Tuğla (Brick) | Walls, paving stones, barrier blocks |
| Çelik (Steel) | Scaffolding poles, iron railings, generators |

## Harvest Mechanics
- Player swings pickaxe at harvestable objects
- Each hit yields material based on material type
- Harvestable objects have finite material pools
- Objects destroyed when pool exhausted

## Material Properties
| Property | Moloz | Tuğla | Çelik |
|----------|-------|-------|-------|
| Harvest Rate | 25/hit | 15/hit | 8/hit |
| Max Stack | 300 | 250 | 150 |
| Place Time | 0.6s | 0.9s | 1.3s |
| Turbo Min | 0.3s | 0.5s | 0.8s |
| Start HP | 60 | 80 | 100 |
| Max HP | 100 | 200 | 350 |
| Harden Time | 5s | 8s | 12s |
| Visual | Broken concrete, rubble | Red brick pattern | Steel beams, rebar |
